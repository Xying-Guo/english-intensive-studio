# English Intensive Studio · 英语精学 v0.4.1

个人使用的实验版本。已完成的检查和仍待验证的真实浏览器功能见 [TESTING.md](TESTING.md)。

Chrome 桌面版的个人 YouTube 精学插件。直接在页面内选句、循环、录音和比较；把学习上下文显示到页面卡片并选中，通过官方 ChatGPT 插件的右键功能提问。**不集成 AI API，不自动发送文字或录音。**

## v0.4.1：字幕跟随，原位提问

- **跟随播放**默认开启：正在说的句子高亮，并在字幕列表内部滚动到可见位置；跨章节时自动切换章节，不用整页滚动追赶字幕。点击字幕定位不会自动关闭跟随。
- 想回头浏览时可关闭跟随。搜索或手动换章节会进入自由浏览；点击**回到当前句**清除搜索、恢复当前播放章节和跟随，即使视频暂停也立即定位。
- 每句的**问 GPT**打开原位小框，不暂停或跳转视频、不切换学习标签，也不展开主网页学习卡片。框内固定保留点击时的原句和时间范围，后续播放不会换掉提问对象。
- 可以输入问题，点击**复制给 GPT**，然后在现有 GPT 侧栏粘贴继续。复制内容含原句、时间戳与前后文；剪贴板不可用时展开已选中的文字供手动复制。可按 Esc 或点击关闭收起小框。
- 这里只准备提问材料，不生成回答，也没有直接唤起其他扩展侧栏的公开接口集成。首次仍需用 ChatGPT 扩展自己的工具栏或右键入口打开 AI。原来的完整学习任务和主网页学习卡片入口仍保留。

## v0.4：理解内容，也用英语参与讨论

- **连续片段**：点击一句确定起点，再点另一句的“选到这里”。支持反向选择、跨章节选择；中间字幕全部保留。片段最长 6 分钟、最多 160 条字幕，建议围绕一个完整观点。Shift+点击另一句文字也可扩展。
- **范围明确**：顶部显示选段时间、字幕数量和原文预览；可回听或清除选择。在“内容与表达”中切换当前选段与当前约五分钟章节。
- **理解与讨论**：围绕原文与问题解释观点、理由、分歧；提示 GPT 区分主张、推测、补充背景和待查证事项，不把视频中的说法当成已核实事实。
- **学习表达**：提取最多 2–3 个值得关注的真实表达，保留时间戳，区分理解即可与主动内化，并标记创作例句。
- **我来说**：只提出一个与片段相关的表达任务，等待用户尝试，不提前提供完整参考答案。实际解释与讨论由 GPT 完成；插件本身没有生成 AI 回答。
- **空白时也能继续**：左栏顶部增加“打开独立学习页”，入口在 iframe 外面。内嵌区未就绪或被改写时会提示，但不会撤销其他组件对页面的改动。独立页绑定原视频标签页，可读取字幕、控制视频和录音；新页的录音会话独立，原有录音不搬移。
- 使用独立页时，在视频标签播放原声，在独立页选段和准备任务；可使用复制入口把内容交给现有 GPT 对话，也可返回视频页的学习卡片右键提问。
- 点击后会新开一个名为 **English Intensive Studio · 英语精学** 的 Chrome 标签页，请在标签栏切换到它。已在用户实际 Chrome 中确认独立页可以正常显示并读取当前视频字幕；真实录音和其他流程的验证边界见 TESTING.md。
- 本轮保留跟读录音与 A/B；自由回应的独立录音模式留待后续。未加入 GPT 回复回传、自动附件上传、云同步或付费 API。

## v0.3：左侧学习栏，中间视频，右侧 GPT

学习区固定停靠左边，不再作为浮窗盖住视频。展开时为它实际预留页面宽度，视频会缩放并在剩余区域居中；官方 GPT 继续使用浏览器右侧栏。

- 点击本插件图标展开左栏。默认宽约 300 像素，高度跟随浏览器可用高度；拖动右侧分隔线调整宽度，点击“重置”恢复默认。
- 点击“收起”变为左侧窄按钮，视频获得更多空间；展开恢复当前页面中调整过的宽度，练习 iframe 和临时录音保留。
- 不再拖动标题栏移动，也不再调节浮窗高度。浏览器或 GPT 侧栏改变可用宽度时，布局跟随调整。
- 学习模式下只隐藏推荐视频，保留 YouTube 原生文字稿及其他内容面板，放在视频下方。原生播放器与控件仍由 YouTube 提供；不重新加载或下载视频。
- 进入全屏时临时释放左栏布局，退出后恢复；离开普通视频页面时释放预留空间。
- 选中字幕后，主网页上的“当前精学句”卡片自动显示原句与时间范围。
- 点击完整学习任务，原句、时间戳、前后文和自定义问题会在卡片中被选中；v0.4.1 起，句旁“问 GPT”改用原位小框。
- 在选中文字上右键，选择官方插件的 **Ask ChatGPT / 询问 ChatGPT**。不必手工复制粘贴。
- 页面卡片处于普通网页 DOM，不在练习 iframe 或 Shadow DOM 中。它是供用户和获得授权的 GPT 读取的文字，不含录音或音频 URL。
- 浏览器的官方右键入口取决于你安装的 ChatGPT 插件、版本和权限。**本版本没有直接调用官方 GPT 扩展的接口，也没有验证 GPT 会自动跟踪每次选句。**
- 保留“备用：复制当前学习上下文”，用于官方右键功能不可用的情况。

官方功能说明：https://learn.chatgpt.com/docs/chrome-extension

## 安装到 Chrome（不用安装 Node 或运行服务器）

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序 / Load unpacked**。
4. 选择下载或解压后包含本文件和 `manifest.json` 的整个项目文件夹。若使用 GitHub 的 **Code → Download ZIP**，请先解压，选择解压后的项目根目录。

5. 在扩展程序菜单里固定 **English Intensive Studio · 英语精学**。
6. 回到 YouTube 视频，刷新一次。点击插件图标，打开页面内学习区。

如果已安装旧版，无需另装一个扩展。在 Chrome 扩展程序页找到本插件，点击重新加载，再刷新 YouTube；确认版本为 **0.4.1**。已有独立学习页也需关闭后从视频页重新打开。重新加载前先下载需要的录音。

v0.3.3 将原生文字稿放在视频下方、说明与评论之前，避免被长评论区推走。自动打开时兼容翻译插件插入的按钮译文，等待延迟出现的按钮，并恢复读取前的页面滚动位置。

v0.3.2 修复打开左栏后原生文字稿消失、空播放器容器占据额外高度的问题；兼容新版 YouTube 文字稿节点，读取英文原文时排除翻译插件插入的译文。

扩展管理页若显示 `Extension context invalidated`，通常表示重载扩展后，旧视频页面的脚本连接失效。必须刷新 YouTube 才能建立新会话；只重载扩展不够。v0.3.1 增加失效后的停止轮询提示和安全连接清理，旧错误记录不会因此自动消失。

如果拿到的是 ZIP，请先解压，再选择解压后的插件目录；不要选择 ZIP 文件，也不要只选择 `manifest.json`。

官方安装说明：https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 开始第一段练习

1. 在 Chrome 打开一个普通 YouTube 视频（`https://www.youtube.com/watch?v=...`）。首版不支持 Shorts、直播或其他视频网站。
2. 等广告结束，确认视频选择了想练习的英文音轨；不要误用自动配音。
3. 展开 YouTube 说明，点击 **内容转文字 / Show transcript**。在 YouTube 中选好英文字幕，清空文字稿搜索。
4. 点击插件图标打开页面学习区，在其中点击 **连接当前视频**，然后 **读取页面文字稿**。无需把视频和音频下载到本地。
5. 插件按约五分钟划分章节，尽量选择邻近的句末边界；点击字幕跳转，或点 **单句循环**。
6. 点 **录音跟练** 进入这一句。可合并下一条字幕、修改起止秒数、设置 A/B 点。
7. 播放原声、调整倍速，然后 **开始录音 → 停止录音**。原声在开始录音时暂停。
8. 选择一次录音，点击 **A → B 顺序对比**。A 来自当前 YouTube 视频中该次录音绑定的目标区间；B 是你的录音，按 1× 播放。
9. 继续重录，无分数门槛。点击 ☆ 固定第一遍，可与最新一次反复比较。
10. 点句旁 **问 GPT**，在原位小框填写问题，点击 **复制给 GPT**，到现有 GPT 侧栏粘贴。也可进入 **内容与表达** 选择完整学习任务，在主网页选中的学习卡片上右键 → **Ask ChatGPT**。需要音频反馈时，仍需主动提供所选录音。

页面内学习区固定连接它所在的视频标签页。打开官方 GPT 侧栏或切去其他标签页不会主动改绑。学习其他视频时，在那个视频页打开本插件。不同页面各有独立会话。

## 字幕与原声

- 首选读取 YouTube 页面上已经加载的文字稿，不调用未公开的字幕下载接口。
- 仅以当前可读取内容为准，不能保证所有视频、语言或 YouTube 页面版本都成功。隐藏重复面板不会重复计数。
- 保留 **粘贴带时间戳文字稿 / SRT / VTT / TXT** 的备用入口。SRT/VTT 保留原始起止时间；只有开始时间时，终点按下一条开始时间推算，末条用视频结束时间估计。可手工微调。
- 视频版本必须与字幕一致。时长超出的字幕会报错；仅凭时长检查不能证明版本一致。
- 原句和播放中字幕分开高亮，练习目标不会跟着播放高亮自动变化。
- 章节是时间戳分组，不切割或导出视频。约五分钟是默认值，末章可以较短。
- YouTube 缓冲、后台节流、广告和字幕自身边界会影响定位。循环适合学习，不保证采样级或无缝精度。
- 点停止会取消插件设置的区间播放。收起学习区只隐藏界面，当前循环和录音可继续；标题栏会显示录音状态。要停录请展开后点击停止。刷新或关闭视频页会结束练习。

## 录音、权限与隐私

- 麦克风只在你主动开始录音时请求，结束后释放。拒绝授权、找不到设备和设备不可用都会提示。
- 嵌入式练习页可能受 Chrome 或 YouTube 麦克风策略影响。无法弹出权限时，点 **打开授权页**，在插件的独立授权页请求麦克风。授权页获得设备后立即释放，不保存测试录音。
- 授权后仍被网页策略阻止时，可点 **打开独立练习页**，在扩展自己的顶层页面练习。独立页有自己的录音会话，不会搬移原页面录音；需要保留的先下载。
- 不需要 `tabCapture`，不录制系统声音，不提取原声音频。建议戴耳机，避免周围声音进入麦克风。
- 每次录音保存开始时的 videoId、原句文本、字幕 ID 和精确起止时间。换句或换视频不会把录音挂到新句子上。
- 可以无限次重录；每句默认保留最近 5 次未固定尝试，加上已固定尝试。全会话最多固定 10 次。
- 为控制内存，全会话临时音频上限约 80 MB；优先释放最早的未固定尝试。单次录音超过约 12 MB 会停止。不保证保留所有历史尝试。
- 录音列表的时长是采集经过时间，包含开始、结束时的静音。不能据此判断发音正确或实际说话速度。
- 录音保存在插件来源的练习 iframe 内存，主网页卡片只接收文字字段，不包含音频 Blob 或录音 URL。**收起保留会话；刷新或关闭视频页、浏览器回收页面、重新加载插件后可能丢失；需要的内容先下载。**
- 每次录音可单独删除；全部删除时会确认。删除本地临时录音不会删除已下载文件，也不会删除用户主动交给其他服务的副本。
- 插件无服务器、分析统计或 AI API 调用。扩展页面 CSP 设置 `connect-src 'none'`，未使用持久化录音数据库或浏览器存储。
- 仅申请 YouTube 网页访问和运行本插件脚本的权限，不再申请侧边栏权限。不申请读取所有网站、历史记录、Cookie API、ChatGPT 网站访问或系统音频权限。
- YouTube 仍会正常请求自己的服务；用户主动使用 GPT 后适用 GPT 的数据规则。这里不承诺浏览器或第三方完全零缓存、零保留。

## 配合 GPT 的边界

- 准备学习卡片只改变网页文字和选区，不会自动提交给 GPT。用户在官方插件入口中选择提问后，才由官方插件处理。可在同一 GPT 对话中继续问。
- 只有当前选中的学习文字会公开显示到 YouTube 页面卡片；不要把不希望网页读取的私人内容写入自定义问题。
- 备用复制只是写入剪贴板，也不会自动提交。
- 提示词保留原文时间戳与上下文，并要求区分真实原句和 AI 创作例句。
- 音频默认使用 Chrome 支持的 WebM/Opus；可能回退为其他格式。不假设每个 GPT 入口都支持上传该格式，必要时另行转换。
- 只提供字幕或语音转成的文字时，GPT 不能据此判断你的实际发音、语调或进步。
- 提供自己的录音也不意味着 GPT 自动获得 YouTube 原声。插件里的 A/B 是实际听音对比，没有隐藏的评分。
- 应用内 AI 讲解、自动转录、词级评估、自动进步判断和跨会话学习记录均未加入第一版。

## 本地开发与验证

生产插件是原生 JavaScript + CSS + Manifest V3，无构建和运行时依赖。

有 Node.js 时，可在此目录运行：

```powershell
npm test
npm run check
npm run preview
```

页面内布局预览：`http://127.0.0.1:4173/preview.html`。

单独的练习界面预览：`http://127.0.0.1:4173/sidepanel.html?preview=1`。

**预览使用明确标注的创作示例和模拟播放时钟。右侧 GPT 区域只是布局示意，没有连接服务；不能代替装入 Chrome 后的实测。**

录音管线测试：页面预览使用 `/preview.html?testRecorder=1`，单独练习预览再加 `&testRecorder=1`。此模式用真实 MediaRecorder 录制 220 Hz 合成音；不打开物理麦克风，不是人声或发音评估。

具体已验证与尚未验证项目见 `TESTING.md`。

## 文件结构

- `manifest.json`：权限、入口与安全策略。
- `background.js`：点击图标展开页面学习区、识别练习 iframe 所在标签页。
- `dock.js`：固定左侧学习栏、页面宽度预留、播放器缩放、分隔线调宽，以及可选中的普通网页文字卡片。
- `content.js`：YouTube 页面适配、播放区间控制、视频身份校验。
- `core.js`：字幕解析、章节、时间定位、录音目标快照和 GPT 上下文。
- `sidepanel.html` / `panel.js` / `studio.css` / `tokens.css`：插件来源的练习 iframe、录音与会话管理。文件名沿用 v0.1，但不再注册 Chrome 侧栏。
- `microphone.html` / `microphone.js`：独立麦克风授权入口。
- `tests/`：逻辑测试与明确隔离的合成音源测试。
- `scripts/`：检查工具与仅绑定 127.0.0.1 的预览服务。

修改生产文件后，在 Chrome 扩展程序管理页重新加载插件，再刷新 YouTube。重新加载前先保存需要的录音。
